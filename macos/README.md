# BetterWeb Mac chrome

Native SwiftUI shell (Apheleia information architecture) for BetterWeb.

- Vertical tabs + omnibox + new-tab CraftRank search
- Page content: sanitized HTML from the sidecar; Playwright/Chromium when that is not enough
- Starts the Python search sidecar on a private loopback port

## Dev run

From the repo root:

```bash
./scripts/run_mac_app.sh
```
